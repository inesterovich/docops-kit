# IDEAS — идеи и решения по ним

> Append-only. Идея не удаляется: отклонённая остаётся с причиной, иначе вернётся через два окна.
> Решение, влияющее на будущие проекты, дополнительно живёт в `docs/decisions/ADR-NNNN-*.md`.

| ID | Идея | Статус | Решение / причина |
|---|---|---|---|
| I-01 | Пресет `fullstack` (backend + frontend в одном репозитории) | отклонена | один проект на репозиторий (ответ пользователя Q1); вернуться, если появится монорепо |
| I-02 | Python-порт линтера для проектов без Node | отклонена | таких проектов нет; при появлении — новый шаблон, а не порт |
| I-03 | Вариант бэкенд-пресета с `jest` | отложена | vitest покрывает ESM+TS без сборщика; jest — если на живом проекте упрёмся |
| I-04 | CI-конфиги в наборе (workflows, pre-commit как файл) | отклонена | CI/CD — проектное решение; набор даёт команду `node checks/docs.test.js` |
| I-05 | RTK Query как дефолтный слой API на фронтенде | отложена | дефолт — Redux Toolkit; слой API выбирает проект и фиксирует в ADR |
