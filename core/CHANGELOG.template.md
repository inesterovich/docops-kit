# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/); версии — semver проекта.

Правила ведения:

- `Unreleased` — всегда первая секция. Промежуточные правки идут сюда, а не в новую версию.
- При релизе `Unreleased` переименовывается в `## X.Y — YYYY-MM-DD`; секции — по убыванию версий.
- Один пункт — одно изменение для пользователя: что было, что стало, чем это грозит.
- Счётчики (число тестов, правил, проверок) в тексте не фиксируются: они меняются молча.
- `CHANGELOG.md` не дублирует `SPEC.md` (как должно быть) и `NOTES.md` (где ошибались).
