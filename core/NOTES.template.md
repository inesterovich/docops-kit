# NOTES.md — журнал ошибок и отступлений

Доказательная база провалов агента и замечаний пользователя. Отвечает на вопрос «где мы ошибались и почему». Правила, выведенные из этих записей, живут в `AGENTS.md` §5 (`R-*`).

- Не дублирует `CHANGELOG.md` (что изменилось) и `SPEC.md` (как должно быть).
- Append-only: старые записи не переписываются; правятся только `Повтор` и `Источник`, если пользователь уточнил.
- Одна запись = один эпизод, ID `E-001` по возрастанию; запись делается в той же сессии, где случился провал, до коммита.
- Повтор класса — **новая** запись с `Повтор: да (E-xxx)`, правило `R-*` переписывается в этой же сессии.
- Без секретов: токен только как `ghp_…`.
- Имя модели не фиксируется: привязка — к сессии, а не к самоотчёту модели.

## Журнал

Образец ниже — не запись: он в блоке кода, чтобы его не приняли за факт.

```text
### E-001 · Короткое название провала

- **Сессия:** S-01 · **Категория:** env | tool | code | test | docs · **Источник:** агент нашёл сам | пользователь
- **Что делал:** команда или правка
- **Как сломалось:** наблюдаемый эффект, текст ошибки
- **Почему:** причина, а не симптом
- **Как починил:** что помогло; что пробовал зря
- **Потери:** команды, токены, ложные «успехи»
- **Правило:** R-N · **Повтор:** нет | да (E-xxx)
```
