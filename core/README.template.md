## Быстрый старт

1. Заполнить плейсхолдеры: незаполненные места помечены двойными фигурными скобками, гейт их ловит.
2. Установить зависимости командой пресета `{{PRESET}}` — если зависимости есть.
3. Прогнать гейт: `{{GATE_COMMAND}}`.

## Структура проекта

| Путь | Что там |
|---|---|
| `AGENTS.md` | контракт агента: правила, Definition of Done, формат ответов |
| `README.md` | этот файл: запуск, структура, ограничения |
| `CHANGELOG.md` | что изменилось и когда |
| `NOTES.md` | журнал ошибок и правила, выведенные из них |
| `HANDOFF.md` | срез состояния между окнами контекста |
| `docs/sessions/` | история сессий, по файлу на окно |

## Документация

Один факт — один документ: владельцы перечислены в `AGENTS.md` §1. Поведение — в `SPEC.md` (профиль `standard` и выше), запуск и настройка — здесь.

## Проверка

```bash
{{GATE_COMMAND}}
```

Гейт проверяет документы, а не код: расхождения «документы ↔ факт», битые относительные ссылки, незаполненные плейсхолдеры, порядок секций `CHANGELOG.md`.

## Ограничения

- CI/CD в набор не входит: где запускать гейт — решение проекта.
- Версии зависимостей в пресетах не фиксируются: они живут в проекте.
- Поведение, которое не помещается в `README.md`, переносится в `SPEC.md` при переходе на профиль `standard`.
