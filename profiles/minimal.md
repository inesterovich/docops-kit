# Профиль `minimal`

Минимальный рабочий каркас: документы, без которых агент теряет контекст между окнами.

## Когда выбирать

- прототип, скрипт, утилита на 1–2 дня;
- отдельного описания поведения нет — оно помещается в `README.md`;
- один человек, один репозиторий.

## Что входит

| Документ | Роль |
|---|---|
| `AGENTS.md` | контракт агента: правила, Definition of Done, формат ответов |
| `README.md` | для человека: запуск, структура, ограничения |
| `CHANGELOG.md` | что и когда изменилось |
| `NOTES.md` | журнал ошибок и правила, выведенные из них |
| `HANDOFF.md` | срез состояния между окнами контекста |
| `docs/sessions/S-NN.md` | история сессий, по файлу на окно |
| `base/.gitignore`, `base/.gitattributes`, `base/.editorconfig`, `base/LICENSE` | копируются как есть |

Не входит: `SPEC.md`, `rules/universal-rules.md`, `docs/decisions/`, `procedures/`, пресеты.

## Команда-гейт

```bash
node checks/docs.test.js
```

Проверяет: наличие документов профиля, относительные ссылки, незаполненные плейсхолдеры, `Unreleased` первой секцией, трассировку `E-*` ↔ `R-*` там, где правила есть.

## Что запрещено

- CI/CD любого вида: workflows, `.github/`, пайплайны. Гейт запускает человек или проект — набор даёт только команду.
- Версии пакетов в пресетах и профилях: версия живёт в проекте.
- Заводить `SPEC.md`, ADR и пресеты «на вырост». Появилось поведение, которое не помещается в `README.md`, — переход на [standard](standard.md).
- Дублировать факт в двух документах: один факт — один владелец (`AGENTS.md` §1).
